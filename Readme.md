🔗 **[Play Now on Web →](https://sreeharigiridharan.github.io/Stick_Wick/)**

## 🕹️ About the Game

**Stick Wick: Gun-Fu** is an intense 2D side-scrolling action game where you step into the shoes of a deadly stick-figure gunslinger. Inspired by the slick, stylish combat of *John Wick*, the game blends lightning-fast movement, precise gunplay, and cinematic slow-motion mechanics into a tight, explosive action experience.

Every encounter is a lethal dance — dodge incoming bullets, return fire with pinpoint accuracy, and use your surroundings to outsmart enemies. Run out of ammo? Don't worry — throw your empty gun at an enemy to stun them, then dash in and steal their weapon. No mercy. No reload screen. Just action.

---

## ⚡ Key Features

- 🔫 **Gun-Fu Combat** — Fluid, fast combat mixing movement and gunplay in perfect sync
- 🐌 **Slow-Motion Mode** — Hold **Right-Click** to activate bullet-time, slowing the world to 20% speed for precise aiming and dodging
- 💨 **Weapon Throw** — When ammo runs out, hurl your gun at an enemy to stun them, then dash and steal their weapon
- 🏃 **Smooth Movement** — Responsive platformer movement with jumping, running, and direction-aware animations
- 🎨 **Animated Character** — Full player animations: idle, run, jump, and more
- 🌐 **WebGL Ready** — Play directly in your browser with no installation required

---

## 🎮 Controls

| Action | Key |
|---|---|
| Move Left / Right | `A` / `D` or `← →` Arrow Keys |
| Jump | `W` / `↑` / `Space` |
| Aim & Shoot | `Left Click` |
| Slow-Motion (Bullet Time) | Hold `Right Click` |
| Weapon Throw | Auto-triggers when ammo is empty |
